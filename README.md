# 📊 SaaS Subscription Churn Prediction

An AI-powered web application that analyzes SaaS customer data and predicts whether a customer may leave a subscription service.

## 📝 Project Overview

Customer churn is a major challenge for Software as a Service (SaaS) businesses. This project uses Machine Learning to estimate customer churn risk and help businesses understand customer retention.

The application provides an interactive dashboard, customer data exploration, and a churn prediction interface.

## ✨ Features

- **Business Dashboard:** Displays customer statistics, active customers, churned customers, and churn rate.
- **Customer Data Explorer:** View, search, and filter customer records.
- **Churn Prediction:** Enter customer details to get a model-based churn prediction.
- **Data Visualization:** View customer status, monthly charges, and tenure charts.
- **CSV Download:** Download filtered customer records.
- **Interactive Interface:** Easy-to-use web application built with Streamlit.

## 📊 Dataset Features

The dataset includes customer information such as:

- CustomerID
- TenureMonths
- MonthlyCharges
- UsageHours
- SupportTickets
- PaymentDelays
- Churn

The `Churn` column represents the target variable used to identify churned customers.

## 🤖 How It Works

1. Customer data is loaded from the dataset.
2. The dashboard displays customer statistics and visualizations.
3. The user enters customer details on the prediction page.
4. The trained Machine Learning model estimates the customer's churn status.
5. The prediction is displayed in the application.

## ⚠️ Disclaimer

Predictions are estimates generated by a trained Machine Learning model. They are not guarantees of actual customer behavior.
